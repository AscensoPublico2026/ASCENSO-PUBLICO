# Manuales de vacantes — Carolina Rueda

Aquí se guardan los **manuales de funciones (PDF)** de las vacantes candidatas que se analicen para **Carolina Rueda**.

- El número de plazas **por ciudad** solo aparece en el manual de funciones (PDF), no en la matriz `Convocatorias_Procuraduria.xlsx`.
- Cada manual se descarga desde el enlace de la columna "Manual de funciones (PDF)" de la matriz, para la vacante correspondiente.
- Nombrar cada archivo con el código de la vacante (ej.: `<CODIGO>-manual.pdf`).
